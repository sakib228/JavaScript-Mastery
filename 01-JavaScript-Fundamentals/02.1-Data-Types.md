# 5. Type Conversion & Type Coercion

## 5.1 Type Conversion

**English Definition:**  
Type conversion is the process of manually changing a value from one data type to another.

**বাংলা ব্যাখ্যা:**  
যখন আমরা নিজেরা কোনো value-এর data type পরিবর্তন করি, তখন তাকে **Type Conversion** (অনেক সময় explicit conversion-ও বলা হয়) বলে।

**Example:**
```javascript
let number = "100";
let convertedNumber = Number(number);

console.log(convertedNumber);        // 100
console.log(typeof convertedNumber); // number
```

### Important Conversion Methods

| Method | Purpose |
| :--- | :--- |
| **`Number()`** | Convert to number |
| **`String()`** | Convert to string |
| **`Boolean()`** | Convert to boolean |
| **`parseInt()`** | Parse integer |
| **`parseFloat()`** | Parse decimal number |

**Example:**
```javascript
console.log(Number("50"));         // 50
console.log(String(100));        // "100"
console.log(Boolean(1));         // true
console.log(parseInt("25.75"));  // 25
console.log(parseFloat("25.75"));// 25.75
```

## 5.2 Type Coercion

**English Definition:**  
Type coercion is the automatic conversion of one data type into another by JavaScript.

**বাংলা ব্যাখ্যা:**  
JavaScript যখন কোনো অপারেশন চালানোর সময় নিজে থেকেই এক data type থেকে অন্য data type-এ রূপান্তর করে, তখন তাকে **Type Coercion** (implicit conversion) বলে।

**Example:**
```javascript
console.log("10" + 5); // "105"
console.log("10" - 5); // 5
console.log("10" * 2); // 20
```

**ব্যাখ্যা:**
* `"10" + 5` → `+` অপারেটরের একপাশে string থাকলে string concatenation হয়ে `"105"` হয়।
* `"10" - 5` → `-` অপারেটর string-কে automatically number-এ রূপান্তর করে (`10 - 5 = 5`)।
* `"10" * 2` → `*` অপারেটর string-কে automatically number-এ রূপান্তর করে (`10 * 2 = 20`)।
