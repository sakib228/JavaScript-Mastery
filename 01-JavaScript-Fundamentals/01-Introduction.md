# 1. Introduction to JavaScript

## 1.1 What is JavaScript?

**English Definition:**  
JavaScript is a high-level, dynamic programming language primarily used to make web pages interactive and dynamic.

**বাংলা ব্যাখ্যা:**  
JavaScript হলো একটি programming language, যার মাধ্যমে website-কে interactive এবং dynamic করা যায়।

**উদাহরণ:**
* Button click করলে কিছু পরিবর্তন হওয়া
* Form validation করা
* API থেকে data নিয়ে website-এ দেখানো
* Dynamic content তৈরি করা
* Web application তৈরি করা

## 1.2 Where is JavaScript Used?

| Area | Usage |
| :--- | :--- |
| **Frontend** | Interactive websites |
| **Backend** | Server-side development (Node.js) |
| **Mobile Apps** | React Native |
| **Desktop Apps** | Electron |
| **Web Applications** | Dynamic applications |
| **Game Development** | Browser-based games |

---

## 1.3 JavaScript Example

```javascript
console.log("Hello, JavaScript!");

let name = "Sakib";

console.log("Welcome " + name);
```

**Output:**
```text
Hello, JavaScript!
Welcome Sakib
```

---

## 1.4 How to Run JavaScript?

1. Browser Console
2. HTML `<script>` tag
3. VS Code with Node.js
4. Online JavaScript Editors

**Example:**

```html
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Learning</title>
</head>
<body>

    <h1>Learning JavaScript</h1>

    <script>
        console.log("Hello World!");
    </script>

</body>
</html>
```
