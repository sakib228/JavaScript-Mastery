# 🚀 JavaScript Mastery

A structured, hands-on archive of my JavaScript learning journey—covering fundamentals, modern ES6+, DOM manipulation, asynchronous programming, problem-solving, and mini projects.

---

## 📌 Overview

- **Goal:** Build strong core JavaScript foundations and practical problem-solving habits.
- **Format:** Topic-wise notes (`.md`), practice scripts (`.js`), and self-contained mini projects.
- **Workflow:** Incremental daily commits as each topic and exercise is completed.

---
